# ГРАНФОРТ — сайт

Одностраничный сайт на [Astro](https://astro.build): защита бамперов для китайских внедорожников.

## Запуск

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/
```

Шрифты (Inter, Unbounded) подключены локально через пакеты `@fontsource`, внешних запросов нет.

## Структура

```text
src/
├── layouts/Layout.astro      # <head>, цвета и отступы (CSS-переменные), шрифты, сброс стилей
├── pages/index.astro         # вся страница: данные (тексты, товары, галерея) → разметка → скрипт → стили
└── assets/images/
    ├── photos/               # фото автомобиля и комплектов
    └── *.png                 # логотип, иконки, стрелки, свечение на первом экране
```

Тексты, товары, контакты и фото галереи заданы массивами в начале `index.astro` — чтобы что-то
поменять, верстку трогать не нужно. Фото Astro при сборке сам ужимает и переводит в WebP;
по клику на фото в галерее оно открывается крупно.

## Адаптив

| Ширина | Что меняется |
|---|---|
| > 1280 | Десктоп, контент 1200 px по центру |
| ≤ 1280 | Уже поля, телефон в шапке скрыт |
| ≤ 1024 | Меню в бургер, первый экран и «О компании» в колонку, сетки по 2 |
| ≤ 768 | Телефон: карточки товаров — горизонтальная карусель, всё в 1 колонку |

## Форма заявки → бэкенд

Форма отправляет заявку `POST`-запросом на адрес из переменной `PUBLIC_LEAD_ENDPOINT`
(по умолчанию `/api/lead`). Скопируйте `.env.example` в `.env`, чтобы указать другой адрес.

### Запрос

```http
POST /api/lead
Content-Type: application/json
Accept: application/json

{
  "name": "Иван",
  "phone": "+79161234567",
  "car": "JAC T9 — передняя защита бампера",
  "website": "",
  "page": "https://granfort.ru/#contact"
}
```

| Поле | Обязательное | Описание |
|---|---|---|
| `name` | да | Имя, 2–80 символов |
| `phone` | да | Телефон в формате `+7XXXXXXXXXX` (фронт уже нормализует) |
| `car` | нет | Марка/модель/год; подставляется сам при клике «Подробнее» в карточке |
| `website` | — | Ловушка для ботов. **Если поле не пустое — заявку нужно молча отбросить** (вернуть 200) |
| `page` | — | Страница, с которой пришла заявка |

### Ответ

- `2xx` (например `{"ok": true}`) — фронт показывает «Спасибо! Заявка отправлена» и очищает форму.
- Любой другой статус или сетевая ошибка — фронт показывает сообщение об ошибке, данные в форме остаются.

### Что должен сделать бэкенд

1. Принять JSON, проверить `name` и `phone` (повторно — фронту доверять нельзя).
2. Отбросить заявку, если заполнено `website`.
3. Отправить письмо на почту владельца (например, через SMTP почтового сервиса).
4. Если бэкенд на другом домене — разрешить CORS для домена сайта.

> Форма собирает персональные данные (имя, телефон) — по 152-ФЗ сервер и почта
> должны быть в России, а на сайте нужна страница политики обработки персональных данных
> (сейчас ссылки на неё — заглушки `#`).
