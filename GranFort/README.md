# ГРАНФОРТ — сайт

Одностраничный сайт на [Astro](https://astro.build): защита бамперов для китайских внедорожников.

## Запуск

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/
```

## Форма заявки → бэкенд

Форма отправляет заявку `POST`-запросом на адрес из переменной `PUBLIC_LEAD_ENDPOINT`
(по умолчанию `/api/lead`). Скопируйте `.env.example` в `.env`, чтобы указать другой адрес.
